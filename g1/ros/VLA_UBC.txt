
# VLA Upper Body Control System (VLA_UBC)

Version: 0.1
Target Platform: Unitree G1
Scope: Upper body manipulation using VLA + ROS2 + hybrid force control
Primary Use Case: Ironing task with dexterous hand + arm coordination

============================================================
1. SYSTEM GOALS
============================================================

The system combines:

- Vision-Language-Action (VLA) reasoning
- Classical motion planning
- Contact-aware impedance/force control
- Dexterous manipulation
- Safety supervision
- Structured logging
- Web-based debugging and visualization

The architecture is designed so that:

- The VLA model performs semantic reasoning and task sequencing
- Classical planners handle geometry and collision avoidance
- Local controllers handle contact physics
- Safety systems retain final authority over execution

The system must support:

- Object grasping
- Tool use
- Contact-rich manipulation
- Hybrid force-position control
- Real-time robot supervision
- Dataset generation for future training

8. VLA SYSTEM USING OLLAMA
============================================================

Purpose:
- Semantic reasoning
- Task decomposition
- Skill sequencing
- Failure recovery

The VLA layer must NEVER directly output:
- joint torques
- kp/kd
- raw motor commands

The VLA layer outputs:
- skill requests
- target tool poses
- semantic plans
- recovery behaviors

11. LOCAL CONTACT CONTROL
============================================================

- Contact approach

- Retreat

============================================================
11.1 HYBRID FORCE-POSITION CONTROL
============================================================

Position-controlled:
- x
- y
- yaw

Force-controlled:
- z / surface normal

Compliant:
- roll
- pitch

Controller:

F_task =
    Kx(x_des - x)
    +
    Dx(dx_des - dx)
    +
    F_feedforward

Joint torque mapping:

tau = J^T F_task

============================================================
11.2 TOOL FRAME CONTROL
