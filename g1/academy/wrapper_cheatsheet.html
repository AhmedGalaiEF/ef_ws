G1 Wrapper Cheatsheet

A reference for academy/sdk_wrapper.py's G1 class and the module-level plumbing it's built from — every row below is read directly off that file, current as of this write-up. Table 1 is the reusable low-level patterns (DDS setup, threads, the RGB-D server, ...); Table 2 is every module-level constant/mapping and what it maps as a convention (not the literal values — see mappings_and_constraints.html for exact ids); Table 3 is every method on G1 itself, grouped and described.

Table 1 — Necessary setups

The reusable low-level patterns every higher-level G1 method is built from — each row names the concrete class/function in sdk_wrapper.py that embodies it.

SetupEmbodied byPurpose / convention
DDS ChannelFactory init_ensure_factory(domain_id, iface) Module-level guard around ChannelFactoryInitialize. One DDS participant per process: stores the first (domain_id, iface) it sees, and raises instead of silently reconnecting if called again with different arguments.
Subscriber (pub/sub read side)class _Latest Wraps one ChannelSubscriber. The callback caches only the newest message plus its receipt time; .get() returns (msg, timestamp). Every state reader in the class is built on one of these.
Publisher, typed command (pub/sub write side)class _Dex3, class _LowCmd, class _ArmSdk Each wraps one ChannelPublisher for a specific command topic (rt/dex3/<side>/cmd, rt/lowcmd, rt/arm_sdk). _LowCmd/_ArmSdk also own a CRC() and recompute it on every write() before publishing.
Lazy client singleton_audio_client(), _motion_client(), _robot_state_client(), _arm_action_client(), _video_client(), _slam_client(), _lowcmd_client(), _arm_sdk_client(), _arm_fk_solver(), _arm_ik_solver(), _dex3_hand() Construct + SetTimeout() + Init() on first use only, then cache on self. Keeps __init__ cheap and never opens a client/solver a given session doesn't end up using.
RPC / service clientclass _SlamClient(Client) Subclasses the generic unitree_sdk2py.rpc.client.Client, registers its API ids via _RegistApi, and calls through a small _call_json(api_id, payload) helper (_Call + JSON encode/decode).
Background thread (cancellable, persistent)class _HeadlightThread(threading.Thread) Re-asserts a value (LedControl) on a fixed interval until a threading.Event is set or a duration elapses; always attempts a safe reset in a finally block, even on error.
RGB-D / RealSense serverget_rgbd()'s ZMQ SUB socket Connects to the external rgbd_server_service over ZeroMQ on port 5555 (tries 0.0.0.0/127.0.0.1/localhost in turn), 3s receive timeout, one [rgb_jpeg, depth_png, depth_scale] multipart frame per call — not a DDS topic.
External TTS processsay()'s Piper subprocess Shells out to a local piper binary (resolved from $G1_PIPER_BIN/$PIPER_BIN/PATH, or ~/.local/bin/piper), then resamples the WAV to mono/16-bit/16kHz with audioop before streaming it through AudioClient.PlayStream.
Environment-variable configurationos.environ.get(...) G1_PIPER_BIN / PIPER_BIN (Piper binary override), G1_SLAM_MAP_PATH (default /home/unitree/test.pcd) — the only two externally-configurable settings in this file.
Freshness / staleness convention_Latest.get() → (msg, timestamp) get_battery()'s 3s window is the only place this class enforces a max-age itself — every other reader just returns whatever is currently cached (possibly None) and leaves the staleness judgment to the caller.

Table 2 — Important mappings

Every module-level constant dict/list in sdk_wrapper.py and what it maps, as a convention — not the literal ids/values (see mappings_and_constraints.html for those).

ConstantMapsConvention / description
FSM_IDSmode name → FSM id Short, memorable name ("zero_torque", "damp", "prepare", "walk", "run") to the integer LocoClient.SetFsmId expects; every *_mode() method is a one-line lookup into this dict.
SERVICE_CATALOGservice name → human description Annotates RobotStateClient.ServiceList() rows (and back-fills any of the five documented names missing from a live response) so get_service() never returns a bare, unexplained string.
HL_ARM_ACTIONSgesture name → action id The vocabulary G1ArmActionClient.ExecuteAction() accepts; every canned-gesture method (clap, hug, ...) is a lookup into this dict via _exec_arm_action.
HL_ARM_ACTION_ALIASESinformal phrasing → canonical HL_ARM_ACTIONS key Lets a caller say "xray" or "two hand kiss" and still resolve correctly; the input is lowercased, underscores→spaces, and whitespace-collapsed before lookup.
LEFT_LEG_JOINTS / RIGHT_LEG_JOINTS / WAIST_JOINTS / LEFT_ARM_JOINTS / RIGHT_ARM_JOINTSbody region → ordered joint-id list The 29-joint low-level array split into its five anatomical groups, in the same index order the firmware uses.
LOWCMD_JOINTSconcatenation of all five groups above The full ordered joint list every rt/lowcmd write iterates over.
UPPER_BODY_JOINTSwaist + both arms The subset _upper_body_pose(), release_arms(), engage_arms(), and move_ll_joint(arm_sdk=True) operate on.
HAND_JOINT_NAMEShand joint index → name Ordered thumb_0..index_1 names for the 7 Dex3 finger/thumb joints; labels get_dex3_hand_sensors() output.
HAND_CMD_TOPICS / HAND_STATE_TOPICSside ("left"/"right") → DDS topic Which rt/dex3/<side>/cmd·state topic each _Dex3 instance publishes/subscribes.
HAND_MAX / HAND_MINside → 7-element joint-limit array Per-joint clamp bounds _clamp_hand() enforces on every Dex3 write.
HAND_THUMB0side → fixed thumb-rotation value The thumb's first joint is held at a constant rest rotation in both HAND_OPEN and HAND_CLOSED rather than driven open/closed like the other six.
HAND_CLOSED / HAND_OPENside → 7-element target array The two named poses open_dex3_hand()/close_dex3_hand() move to; HAND_OPEN is derived from HAND_CLOSED by picking whichever bound (HAND_MIN/HAND_MAX) is farther away, per joint.
BMS_TOPICSordered list of battery topic names The dedicated-topic search order get_battery() tries before falling back to the lowstate-embedded BMS block.
INSPIRE_CONFIGSside → (host, port, unit_id) Modbus TCP endpoint for each Inspire hand — a separate network path from every DDS topic above.
INSPIRE_OPEN / INSPIRE_CLOSE6-element raw register-value array The open/close actuator targets _modbus_move() writes; raw register units, not joint angles, and not clamped the way Dex3 targets are.
_NAMED_COLORScolor name → (r,g,b) The small named-color vocabulary _parse_color() accepts alongside #RRGGBB and "R,G,B" strings.
_PIPER_VOICESlanguage code → Piper voice-model name Resolves say(language=...)'s short codes/aliases to the actual .onnx voice-model file to load.
SLAM_POINT_TOPICSordered list of point-cloud topic names Every topic get_point_cloud() considers; it decodes from whichever has the newest timestamp.

Table 3 — G1 class components

Every method on G1, grouped by role. Constructor Private Public

Constructor

MethodDescription
Ctor__init__(iface, domain_id=0) The only entry point. Stores iface/domain_id, calls the module-level _ensure_factory guard (so ChannelFactoryInitialize runs at most once per process), constructs+Init()s a LocoClient, initializes every lazy-client slot to None/{}, reads G1_SLAM_MAP_PATH from the environment, and eagerly constructs every _Latest state subscriber the class ever reads from (rt/lowstate, rt/odommodestate, rt/sportmodestate, rt/odom, rt/unitree/slam_mapping/odom, the four SLAM cloud topics, rt/slam_info, rt/slam_key_info, rt/audio_msg, and every BMS topic/type combination) — these are the only things not lazy, since a fresh state read must be possible from the moment the object exists.

Private_audio_client() Lazily constructs and caches an AudioClient (5s timeout); backs say() and set_headlight().
Private_arm_action_client() Lazily constructs and caches a G1ArmActionClient (10s timeout); backs every high-level gesture method.

Private_arm_ik_solver(side) Lazily constructs and caches one ArmIK(side, "dls", max_iter=24, tol_pos_m=0.005, tol_rot_rad=0.02) per side; same import guard as _arm_fk_solver.
Private_dex3_hand(side) Lazily constructs and caches one _Dex3 hand wrapper (publisher + tactile-state subscriber) per side.
Private_lowstate_msg() Returns the cached rt/lowstate message (or None) — the single read point almost every state/control method goes through.
Private_sport_msg() Returns whichever of rt/odommodestate/rt/sportmodestate has the newer timestamp — the fallback-preferring read point for gait/odom.
Private_string_data(msg) Extracts and stringifies a DDS String_ message's .data field, or None if msg is None.
Private_latest_cloud_msg() Scans the four SLAM point-cloud subscribers and returns the (topic, msg, timestamp) of whichever is freshest.
Private_slam_pose() Parses the current SLAM pose from get_slam_info()'s JSON text; if parsing fails or returns nothing, falls back to the last known good pose instead of returning None.
Private_hand_error(hand, action, exc=None) Builds the standard {"ok": False, "error": "hand not detected"}-shaped dict every hand method returns when a hand isn't present or its call raised.
Private_current_q_mode(timeout=3.0) Polls rt/lowstate until a message arrives (or times out), returning the full 29-joint q array plus mode_machine — the read point every low-level joint write starts from.
Private_upper_body_pose(timeout=3.0) Same as _current_q_mode but sliced down to just the 17 UPPER_BODY_JOINTS (waist + both arms), keyed by joint id.
Private_odom_pose(msg) Extracts (x, y, yaw) from an odometry-shaped message, trying the standard pose.pose.position/orientation path first and an SDK-object-style .position()/.imu_state().quaternion() path as a fallback.
Private_exec_arm_action(action, release_after_s=None) Resolves a gesture name (or raw id) via HL_ARM_ACTIONS, calls ExecuteAction, and optionally sleeps then calls the "release arm" action afterward — the shared implementation behind every one of the six HL gesture methods.

State monitoring

MethodDescription
Publicget_state() The one-call snapshot: FSM id/mode (raw RPC calls), the current motion-switcher mode name/code, gait, battery, lowstate, services, and SLAM info — all in one dict.
Publicget_lowstate() Normalizes the raw rt/lowstate message into {timestamp, joint_positions, joint_velocities, joint_torques, imu}, plus the raw message under "raw".
Publicget_odom() Tries rt/odommodestate/rt/sportmodestate first (position/velocity/imu/mode/gait); falls back to rt/odom, then rt/unitree/slam_mapping/odom, returning a parsed (x,y,yaw) pose from whichever source is available.
Publicget_imus() Reads the IMU block off whichever of lowstate/sport-state has one: rpy/gyro/acc/quaternion/temperature, each independently guarded so one missing field doesn't fail the whole call.
Publicget_battery() Tries each dedicated BMS topic in order (3s freshness window) before falling back to bms_state/power_v/power_a/bit_flag embedded in rt/lowstate.
Publicget_slam_info() Returns the raw JSON text from rt/slam_info, falling back to rt/slam_key_info.
Publicget_rgbd() Connects a ZMQ SUB socket to the rgbd_server_service endpoint and returns the newest {rgb_jpeg, depth_png, depth_scale} multipart frame.
Publicget_point_cloud() Decodes x/y/z out of the freshest SLAM PointCloud2_ message's raw byte buffer using its own fields/point_step layout, decimating to at most ~20000 points.
Publicget_mic_input(duration_s=0.0, poll_s=0.05) Polls rt/audio_msg for up to duration_s seconds (0 = one immediate check), de-duplicating by (timestamp, raw_text) and parsing each message's JSON payload for a "text" field.
Publicget_dex3_hand_sensors(hand="both") Returns each requested Dex3 hand's joint q/dq/tau plus tactile pressure/temperature/lost-sensor arrays, or the standard hand-not-detected error dict.
Publicget_inspire_hand_sensors(hand="both") Always returns the hand-not-detected error dict for each requested side — no tactile read-back is implemented for Inspire hands in this wrapper.
Publicget_gait() Reads gait_type/gaitType/gait off the sport-state message (trying each name in turn); falls back to the last value toggle_gait() itself set if the robot hasn't reported one yet.

MethodDescription
Publicget_service(service=None) Lists every service from RobotStateClient.ServiceList(), annotated via SERVICE_CATALOG; falls back to just the catalog (status/protected as None) if the installed SDK doesn't expose ServiceList. With service given, returns just that row (case-insensitive match) or None.
Publictoggle_service(service) Looks up the named service via get_service, flips it with ServiceSwitch based on its currently-reported status, and returns the name/previous-status/new-enabled-flag/return-code.

Publicprepare_mode() SetFsmId(FSM_IDS["prepare"]) — stand-up sequencing.
Publicwalk_mode() SetFsmId(FSM_IDS["walk"]).
Publicrun_mode() SetFsmId(FSM_IDS["run"]).
Publictoggle_dev_mode() Exactly toggle_service("ai_sport") — flips whether the main locomotion/AI service owns the motors.
Publictoggle_gait() Flips a locally-tracked gait flag: to enable, tries SetBalanceMode(1)/SetGaitType(1) (whichever the loaded SDK exposes); to disable, tries BalanceStand(0) then SetBalanceMode(0)/SetGaitType(0), then falls back to re-entering walk via SetFsmId. Records every attempted method/code pair.

Navigation & SLAM

MethodDescription
Publicloco_move(vx, vy, vyaw, duration_s=2) Starts a continuous Move, sleeps duration_s, and always calls loco_stop() in a finally block so an exception mid-sleep can't leave the robot moving.
Publicloco_stop() StopMove() if the loaded LocoClient exposes it, else a zero-velocity non-continuous Move.
Publicstart_mapping() Records the current SLAM pose as the mapping session's starting pose, then calls the SLAM RPC's start_mapping("indoor").
Publicstop_mapping() Calls the SLAM RPC's stop_mapping() with no save path (the "stop without save" API id).
Publicrelocate() Re-localizes against the saved map at the current (or last-known/initial) pose; on success, updates both the cached "last" and "initial" poses.
Publicadd_map_pose() Appends the current (or last-known/initial) SLAM pose onto an internal path-points queue for navigate(); raises if no pose is available yet.
Publicnavigate(map_pose) Optionally enqueues one more (x,y,yaw) point, then sends a pose_nav RPC for each queued point in order, now waiting for each to be confirmed reached (_wait_for_slam_arrival(), preferring the robot's own is_arrived flag over an xy-distance check) before sending the next — previously it fired every queued pose_nav back-to-back with no wait, so each call pre-empted the last before the robot got anywhere near it and only the final point actually had any effect. Stops early on a non-zero return code, a timeout, or an obstacle-blocked path (get_slam_notice()); always clears the queue afterward.
Publicget_slam_notice() New. Returns the latest parsed errorCode/info/is_arrived/obsInfo status from whichever of rt/slam_key_info / rt/slam_info is newer — obstacle_blocked is true while the nav stack currently has the path blocked.

Saved LL pose sequences

Open/close, teach/repeat, and the arm_sdk ownership handoff (release / re-engage, i.e. “unrelease”) all live here as the closest existing grouping to what those concepts map to in this file today.

MethodDescription
Publicopen_dex3_hand(hand="both") Moves the requested Dex3 hand(s) to HAND_OPEN; returns per-hand ok/error dicts (a single dict if one side was requested, a dict keyed by side otherwise).
Publicclose_dex3_hand(hand="both") Same shape, moves to HAND_CLOSED.
Publicopen_inspire_hand(hand="both") Sends INSPIRE_OPEN register values over Modbus TCP to the requested hand(s)' configured IP/port.
Publicclose_inspire_hand(hand="both") Sends INSPIRE_CLOSE register values the same way.
Publicrelease_arms() Ramps the rt/arm_sdk weight from 1→0 over 151 steps (~3s) on a smoothstep ease curve, holding the upper-body pose fixed while gains fade out — hands control back to the default controller. The “release” half of the handoff.
Publicengage_arms() Ramps the weight 0→1 over 51 steps (~1s), taking rt/arm_sdk ownership of the current upper-body pose. The “unrelease” / re-engage half of the handoff.
Publicteach(arm="both") Not implemented — raises NotImplementedError. A pose/sequence-recording method is anticipated by the name but not present in this wrapper version.
Publicrepeat() Not implemented — raises NotImplementedError. The playback counterpart to teach; also absent.
No interpolate method exists on G1 in this file. Smooth interpolation is inlined inside release_arms/engage_arms/ik_move_ee/extend_arm rather than exposed as its own reusable method — solved/lib_solved.py's Task 8 (interpolate_to_ll_pose) is where a standalone version of that idea actually gets built, alongside a working teach/repeat pair.

LL arm control

MethodDescription
Publicik_move_ee(hand="right", delta_q=None, pose_increment=None, max_speed=0.35, max_dq=0.2, rate_hz=50.0, position_only=False) Solves a small 3- or 6-element Cartesian pose increment ([dx,dy,dz] or [dx,dy,dz,droll,dpitch,dyaw]) with damped-least-squares IK (or a position-only shoulder/elbow solver when position_only=True), clips the resulting joint delta to max_dq, and ramps to it via rt/arm_sdk in eased, speed-limited steps. Returns success=False (and does not move) if the solve fails.
Publicextend_arm(hand="right", dx=0.08, dy=0.08, dz=0.04, steps=3, max_speed=0.25, max_dq=0.15, rate_hz=50.0) Splits a total Cartesian displacement into steps equal position-only ik_move_ee calls, so the arm advances toward a forward/extended reach in small bounded increments rather than one large solve.

LL dev mode control

MethodDescription
Publicmove_ll_joint(joint_id, q, dq, kp, kd, tau, arm_sdk=True) Two distinct low-level paths selected by arm_sdk. With arm_sdk=True (default): moves one joint from UPPER_BODY_JOINTS through the rt/arm_sdk-assisted publisher, holding the rest of the upper body at its last observed pose. With arm_sdk=False: targets any of the 29 LOWCMD_JOINTS directly through the raw whole-body rt/lowcmd publisher — the true “developer mode” path, which requires ai_sport released/dev mode entered first (see toggle_dev_mode()) — holding every other joint at its currently observed q.
