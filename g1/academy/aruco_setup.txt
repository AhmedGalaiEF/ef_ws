# ArUco Marker Setup: Pickup and Dropdown

Instructions for generating, printing, and mounting the two physical ArUco markers used by
Task 12 (`task12_perception_and_pose_estimation_pipeline.ipynb`) and Task 13
(`task13_final_task.ipynb`) via `util.DeliveryPipeline.aruco_pose`.

## 1. Read this first: the pipeline does not filter by marker ID

`DeliveryPipeline.aruco_pose()` in `util.py` calls `cv2.aruco.detectMarkers(...)` and always
uses the **first** entry in `corners`/`ids` - it does not check which ID was found:

    corners, ids, _ = aruco.detectMarkers(bgr_image, dictionary)
    if ids is None or not len(corners):
        raise RuntimeError("No ArUco marker detected.")
    rvecs, tvecs, _ = aruco.estimatePoseSingleMarkers(corners, float(marker_length_m), ...)
    rvec, tvec = rvecs[0].reshape(3), tvecs[0].reshape(3)

Consequence: the pickup marker and the dropdown marker must **never both be visible in the
same frame** at the moment `aruco_pose()` is called. If both are in view, you get whichever one
OpenCV happened to list first - not necessarily the one you meant. Physically separate the two
stations so the camera's field of view only ever contains one marker at detection time (see
Section 5), or keep the other one covered/turned away while you work the first.

## 2. Pick two distinct marker IDs and a dictionary

- Dictionary: `cv2.aruco.DICT_4X4_50` (the default `dictionary_name` in `aruco_pose`). 4x4-bit
  interior grid, 50 possible IDs (0-49). Do not mix dictionaries between the two markers - both
  must be generated from the same `DICT_4X4_50` table so the same `aruco_pose(..., dictionary_name="DICT_4X4_50")`
  call detects either one.
- Recommended IDs: `0` for pickup, `1` for dropdown. Any two distinct IDs in range work; low IDs
  just make the printed pattern easier to eyeball-identify. Record whichever IDs you actually use
  in the calibration notes next to `camera_to_base`/`wrist_to_palm`, so a future participant knows
  which physical sheet is which station.

## 3. Generate the printable images

Run this once (OpenCV >= 4.7; `cv2.aruco.generateImageMarker` replaced the older `drawMarker`):

    import cv2
    aruco_dict = cv2.aruco.getPredefinedDictionary(cv2.aruco.DICT_4X4_50)
    for marker_id, name in ((0, "pickup"), (1, "dropdown")):
        marker_px = 800  # high resolution -> crisp edges when printed
        img = cv2.aruco.generateImageMarker(aruco_dict, marker_id, marker_px, borderBits=1)
        cv2.imwrite(f"aruco_{name}_id{marker_id}.png", img)

If your OpenCV build predates 4.7, use `cv2.aruco.drawMarker(aruco_dict, marker_id, marker_px)`
instead - same output.

Add a white quiet-zone margin before printing: paste each generated image onto a larger plain
white canvas so there is a blank white border around the black/white pattern at least ~20% of
the marker's own width on every side. `detectMarkers` relies on strong contrast at the marker's
edge; a marker printed edge-to-edge with the paper (no margin) detects less reliably under real
lighting.

## 4. Print at exact physical scale

- In the print dialog, disable "fit to page" / "scale to fit" / "shrink to fit" - print at
  **100% / actual size**. Any auto-scaling changes the physical marker size without changing the
  file, and `aruco_pose`'s translation output is computed directly from the `marker_length_m`
  you tell it, not from anything measured in the image - a silently rescaled printout produces a
  systematically wrong distance estimate.
- Use matte (non-glossy) paper or cardstock. Glossy paper glares under the RealSense's IR/RGB
  illumination and can wash out corners the detector needs.
- After printing, **measure the actual printed black square with a ruler or calipers** (edge to
  edge of the black-bordered square, not the whole page) and use that measured value - not the
  nominal one you designed for - as `marker_length_m`. Printers and paper feed commonly introduce
  a percent or two of scale error, and IK end-effector targets are directly proportional to this
  number.
- Mount the printout on a rigid flat backing (foam board, thin acrylic, stiff cardboard). A
  curled or bent sheet distorts the corner geometry `estimatePoseSingleMarkers` solves against
  and biases the pose, especially rotation.

## 5. Sizing and placement per station

- **Pickup marker**: sized and placed for the close range the arm operates at during grasp
  approach (roughly the reach used by `extend_arm_forward`/`ik_move_ee` in Tasks 8/10 - typically
  well under 0.5 m from the camera). A 4-6 cm edge length is a reasonable starting point; verify
  the marker is still comfortably resolvable (not blurry, not clipped) in a captured `get_rgbd()`
  frame at that distance before relying on it. Fix the marker rigidly to (or immediately behind,
  at a known fixed offset from) the object to be picked up, facing the camera as close to
  head-on as practical - keep the marker's tilt away from the camera axis under ~30 degrees, and
  make sure the gripper does not occlude it until the final grasp step.
- **Dropdown marker**: mounted at the fixed drop location (table edge, bin, tray), sized for
  whatever distance the robot approaches that station from - use a larger edge length than the
  pickup marker if the drop point is farther from the camera, so it still fills enough pixels to
  detect reliably. Keep it unobstructed and facing the direction the robot approaches from.
- Light both stations evenly; avoid direct backlighting (a bright window or lamp directly behind
  the marker) and hard shadows falling across the marker face.

## 6. Update the notebooks with your measured values

In `task12_perception_and_pose_estimation_pipeline.ipynb` and
`task13_final_task.ipynb`, set `marker_length_m` to your Section 4 measured value (in meters,
e.g. `0.045` for a 45 mm square) before calling `pipeline.aruco_pose(...)`. If you used marker
IDs other than the pickup/dropdown convention above, note that `aruco_pose` still does not
filter by ID (Section 1) - correctness depends entirely on keeping the two markers out of the
same frame, not on the ID values themselves.

## 7. Validate before trusting it in the capstone

- Run Task 12's detection/pose cells with only the pickup marker in frame; confirm exactly one
  detection and a translation that roughly matches a tape-measured ground-truth distance from
  camera to marker (within a few centimeters). Repeat with only the dropdown marker in frame.
- Re-check both after any reprint, remount, or camera/calibration change - a new printout is a
  new physical object and needs its edge length re-measured (Section 4), not assumed identical
  to the last one.
