Getting started the order these actually get used in

If this is your first session, this is the sequence — everything else on this page is something one of these steps points you at.

  1. Environment already set up for you by setup_python_cyclonedds_unitree_sdk.sh and, if you're on your own laptop rather than the lab Jetson, setup_wpa_supplicant_wlan0.sh to join the robot's network — see Setup scripts below.
  2. Open 01_jupyter_dds_speech_headlights_participant.ipynb and work through notebooks 01–04 in order — each one imports sdk_wrapper.py and, where noted, util.py/slam_util.py.
  3. Keep mappings_and_constraints.html and wrapper_cheatsheet.html open in another tab while you work — they're the two documents you'll actually reach for mid-task.
  4. Notebook 04's capstone needs a printed ArUco marker — that's aruco_setup.html.
  5. 05_bonus_services_audio_chatbot_participant.ipynb is optional, after 01–04.

Notebooks

Five Jupyter notebooks, each with ## Task N markdown cells and pass/# TODO placeholders for you to fill in. Work through 01–04 in order; 05 is a separate, optional bonus track.

FileKindCovers
01_jupyter_dds_speech_headlights_participant.ipynbcore DDS channel setup and pub/sub basics; making the robot speak and change its headlight color.
02_state_modes_locomotion_participant.ipynbcore Reading robot state, switching FSM modes/services, and basic walking commands.
03_arm_and_dex3_control_participant.ipynbcore Arm gestures and low-level arm control, plus Dex3 hand gripping.
04_perception_delivery_capstone_participant.ipynbcore SLAM mapping/navigation and the perception-based delivery capstone (detect → validate → grasp).
05_bonus_services_audio_chatbot_participant.ipynbbonus Optional: packaging a real ROS 2 node, a minimal from-scratch robot bridge class, and wiring supplied ASR/OpenAI modules to voice input.

Python modules

Imported by the notebooks above, or run standalone. You read these, you don't edit them.

FileKindWhat it's for
sdk_wrapper.pymodule The finished G1 wrapper class — one object per robot session, covering state reads, mode switching, locomotion, SLAM, arm/hand control, and perception. This is what notebooks 01–04 actually call. Full method-by-method reference: wrapper_cheatsheet.html.
util.pymodule Support that's impractical to retype by hand: documented FSM/joint/hand id maps, Piper text-to-speech conversion and playback, and the integration points for the supplied perception/IK pipelines used in notebook 04.
slam_util.pymodule Standalone SLAM support for notebook 04: the deployed mapping/relocate/navigate RPC calls, pose parsing, and named-point persistence. No dependency on sdk_wrapper.py.
mode_control.pyscript A small Dash web app with one button per FSM state (Zero Torque, Damp, Prepare, Walk, Run, ...) for manual mode control from a browser, instead of from code. Run it directly (python3 mode_control.py); it does not get imported by the notebooks.
realsense_rgbd_zmq_stream.pyscript Publishes the RealSense camera's RGB + depth frames over a ZeroMQ socket. This is the server side of what sdk_wrapper.G1.get_rgbd() connects to — run it once, near the camera, before any notebook that needs perception.

Setup scripts

One-time environment setup. You shouldn't need these mid-course unless something's broken.

FileKindWhat it's for
setup_python_cyclonedds_unitree_sdk.shsetup Builds the reference Python environment: CycloneDDS, the Unitree SDK, Piper TTS voices, and the rest of what a notebook might import. Example/reference only — review versions and paths before running it yourself.
setup_wpa_supplicant_wlan0.shsetup Connects wlan0 to a Wi-Fi network via wpa_supplicant. Usage: sudo ./setup_wpa_supplicant_wlan0.sh SSID PASSPHRASE.

Reference docs

Browsable HTML — no server needed, just open the file. Keep these handy while working through the notebooks rather than reading them cover-to-cover first.

FileKindWhat it's for
mappings_and_constraints.htmlreference FSM ids, joint indices, topic names, and safety constraints for the whole robot — the one place every id/limit used across the notebooks is collected and explained.
wrapper_cheatsheet.htmlreference Every method on sdk_wrapper.G1, grouped and described, plus the underlying DDS setup patterns and constant mappings it's built from.
aruco_setup.htmlreference Printing and mounting instructions for the ArUco markers notebook 04's capstone task detects and picks up.
Working solutions for every task exist for instructor reference but aren't part of this folder's participant materials — if a task has you stuck, re-read the relevant knowledge section in mappings_and_constraints.html/wrapper_cheatsheet.html or ask an instructor rather than looking for an answer key here.
